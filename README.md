## About

This entry sums up the world news of 26 November 2026 in a single 1024x1024 image. The image covers the day's major stories: the Wang Fuk Court fire in Hong Kong, Xi's graft probe reaching Chen Jining, the first Pakistani astronaut heading to Tiangong, the Cartagena hostage situation, North Korea expelling a Swiss diplomat, and the Thanksgiving storm on the US East Coast.

## How to run

```sh
node main.ts
```

Running `main.ts` copies `entry.png` to `/output/entry.png`.
